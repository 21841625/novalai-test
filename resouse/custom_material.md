# 自定义参考素材（AI生成章节可参考素材）
==================================================
【一、网络梗/流行语（可适度使用）】
1. 主打一个XXX
2. 你人还怪好嘞
3. CPU烧了
4. 这波操作我给满分
5. 纯纯大冤种

【二、写作手法与句式样例】
1. 动作优先，情绪后置：不要写“他很害怕”，要写“指尖攥白，喉结滚了滚，没敢出声”
2. 短句子制造紧张感：悬疑/战斗场景，每句不超过15字
3. 画面感描写：用视觉+听觉+触觉，不用抽象词
4. 钩子结尾：每章最后1句必须留悬念

【三、禁止使用的套话】
1. 禁止使用“电光火石之间”
2. 禁止使用“心中一凛”
3. 禁止使用“果不其然”
