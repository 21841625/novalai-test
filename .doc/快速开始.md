# autonovel 快速开始指南

## 环境配置

```bash
# 1. 复制环境变量模板
cp .env.example .env

# 2. 编辑 .env 文件，配置 API 密钥
#    推荐使用 DeepSeek（国内可用）
#    AUTONOVEL_API_PROVIDER=deepseek
#    DEEPSEEK_API_KEY=你的密钥

# 3. 安装依赖
uv sync
```

## 创建新小说

```bash
# 1. 创建小说分支（每个小说独立分支）
git checkout -b autonovel/我的小说名

# 2. 创建 seed.txt（故事核心设定）
#    内容包含：标题、钩子、世界、魔法/代价、张力、主题
```

## 运行完整管道

```bash
# 方式1：自动运行所有阶段（推荐）
uv run python run_pipeline.py --from-scratch

# 方式2：分步运行
uv run python run_pipeline.py --phase foundation   # 基础构建
uv run python run_pipeline.py --phase drafting     # 初稿生成
uv run python run_pipeline.py --phase revision    # 修订优化
uv run python run_pipeline.py --phase export      # 导出格式
```

## 手动运行各阶段

### 基础构建

```bash
uv run python gen_world.py > world.md          # 生成世界设定
uv run python gen_characters.py > characters.md # 生成角色注册表
uv run python gen_outline.py > outline.md      # 生成大纲
```

### 初稿生成

```bash
uv run python run_drafts.py                    # 批量生成所有章节
# 或
uv run python draft_chapter.py --chapter=5     # 生成单章
```

### 评估与修订

```bash
uv run python evaluate.py --chapter=5          # 评估单章
uv run python adversarial_edit.py all          # 对抗性编辑分析
uv run python compare_chapters.py              # 章节对比排名
uv run python gen_revision.py 5 briefs/ch05.md # 修订章节
```

### 导出格式

```bash
uv run python typeset/build_tex.py             # 生成 LaTeX
cd typeset && tectonic novel.tex               # 编译 PDF
```

## 生成种子概念

```bash
# 方式1：AI生成多个概念变体
uv run python seed.py --riff "你的主题描述"

# 方式2：直接创建 seed.txt 文件
# 写入标题、钩子、世界、魔法/代价、张力、主题
```

## 切换小说

```bash
git checkout autonovel/另一部小说   # 切换到其他小说分支
git branch | grep autonovel/        # 查看所有小说分支
```

## 注意事项

1. 首次运行需配置 `.env` 中的 API 密钥
2. 建议为每部小说创建独立分支
3. 完整管道运行时间较长（15-30小时）
4. API 费用较高，测试阶段建议使用低成本模型
